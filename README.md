# 吞嚥照護本 (SwallowCare)

本專案提供吞嚥照護與飲食質地評估指引，包含網頁版展示與 Android 原生 App。

## 目錄結構

- [index.html](file:///home/ming/pinyen_ui/index.html)：主網頁與手機預覽展示介面（已支援手機全螢幕響應式）。
- [android/](file:///home/ming/pinyen_ui/android/)：完整的 **Android Studio (WebView) 原生專案**，可直接匯入 Android Studio 編譯成 `.apk` 檔案安裝至 Android 手機。
- [吞嚥照護本/](file:///home/ming/pinyen_ui/%E5%90%9E%E5%9A%A5%E7%85%A7%E8%AD%B7%E6%9C%AC/)：專案資源與備份文件。

詳細編譯與使用步驟請參考 [android/README.md](file:///home/ming/pinyen_ui/android/README.md)。
